# Portfolio CMS

This Laravel application is the administration and delivery layer for the portfolio frontend in the repository root. It serves the existing root `index.html`, CSS, and JavaScript; it does not contain a separate portfolio theme.

Use the repository-level [setup and operations guide](../README.md) for MySQL configuration, migrations, administrator creation, the integrated live preview, tests, and deployment.

The application and test suite use MySQL. Local and test `.env` files are ignored and must never be committed.
