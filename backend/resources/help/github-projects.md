## What it does

The site looks through your public GitHub repositories and lists new or changed ones for review. Nothing is ever published automatically.

## Reviewing a repository

Each new repository found becomes a **private draft project**. It isn't shown on the site.

1. Read what was found: name, description, language and licence.
2. Check the source, the licence and who contributed.
3. Tick that you've reviewed it, then **Approve review** or **Reject candidate**.
4. To show an approved project, finish its details and publish it on the [Projects](/admin/projects) page. Approving never publishes anything by itself.

## Good to know

- Only public repositories are read, through GitHub's public API. No GitHub password or token is stored.
- Forks and archived repositories are skipped.
- README files aren't read, and features are never made up. You write the project description.
- Owning the GitHub account doesn't prove you wrote all the code. Credit contributors where it's due.
