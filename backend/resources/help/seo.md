## What it does

SEO monitoring scans the real public site, the home page and up to 50 published project pages, plus `robots.txt` and the sitemap. It lists technical problems that can stop search engines reading your pages properly.

## Running a scan

Press **Scan public website**. Scans also run every night once the scheduler is installed. Each finding says what was found, on which page, how serious it is, and what to do. It's marked **resolved** automatically when a later scan no longer finds it.

## Fixing findings

Findings link to the place to fix them, usually the [live site editor](/admin/site-editor) or a project. Common ones:

- **Missing or duplicate titles and descriptions**: give each page a specific, truthful title and description.
- **Missing alt text**: describe images in the [media library](/admin/media).
- **Thin content**: a project page with very little text. Add useful context about the work. Word count is a hint, not a target.
- **Structured data**: details that help search engines understand the page.

## Good to know

> A clean scan doesn't guarantee indexing or rankings. Only Google decides those. Search Console on the [Analytics](/admin/analytics) page shows how you actually appear.

- Nothing is ever rewritten automatically. You stay in control of the wording.
