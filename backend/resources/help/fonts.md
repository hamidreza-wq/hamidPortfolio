## What it does

The font library holds the fonts your site can use. Add them from **Google Fonts** in a couple of clicks, or upload your own files, then choose them for headings or body text in the [live site editor](/admin/site-editor) or in a [theme](/admin/themes).

## Adding a Google font

1. Under **Add from Google Fonts**, search for a family, such as "Playfair" or "Mono". **See it on Google Fonts** opens its page if you want to look at it first.
2. Tick the **weights** you want. 400 (regular) and 700 (bold) are ticked for you. Choose **Italic** if you want the italic style.
3. Press **Add to library**. Each weight becomes its own entry under **Your fonts**, with a sample line set in that font.

The font file is copied onto your site, so visitors' browsers never contact Google. That's the privacy-friendly way to use Google Fonts, because it means visitors' IP addresses aren't sent to Google. Every Google font has an open licence that allows website use, and the library records which one and links to the specimen page.

> Without a Google Fonts API key, the search shows about 40 popular families. You can still add any Google font by typing its name exactly as Google Fonts shows it. To search the whole catalogue, ask whoever manages the server to add a free `GOOGLE_FONTS_API_KEY`.

## Uploading your own font

Open **Upload a font file instead** and choose a **WOFF2**, **WOFF**, **TTF** or **OTF** file, up to 2 MB. Give it a family label, set its weight and style, add where it came from and its licence, and confirm you have the right to use it on the web. Upload each weight or style as a separate file.

## Good to know

> Only upload fonts whose licence allows web embedding. Many desktop font licences don't.

- Every font, from Google or uploaded, is checked to be a real font file before it's saved.
- Each weight is a separate choice in the editor. For bold headings, choose the 700 weight as the heading font.
- A font in use by the site can't be deactivated or deleted.
- The built-in choices (Inter, System UI, Georgia and Monospace) need nothing added.
