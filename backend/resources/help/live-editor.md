## What it does

The live site editor changes the text and look of your portfolio with a preview beside it. It covers:

- **Profile & links**: your name, title, GitHub profile, contact email and footer note.
- **Search & sharing**: the page title, description, canonical address, language, Open Graph overrides, the sharing image, and whether search engines may index the site.
- **Visual system**: the five colours, body and heading fonts, content width, section spacing, card corners, motion and the particle field.
- **Portfolio sections**: the title, subtitle, text, order, visibility, spacing and images of each built-in section.
- **Skills & categories**: the groups and skills shown on the site.
- **Publishing**: maintenance mode.

## Making a change

1. Edit any field. The preview on the right updates as you type, using the same styles and scripts as the public site.
2. When it looks right, press **Publish changes**. Only then do visitors see it.
3. If you change your mind before publishing, reload the page to discard the draft.

## Colour presets

**Color presets** at the top load a saved palette into the draft. **Save draft palette as preset** stores the current colours. For whole-site looks (fonts, spacing and motion too), use [Themes](/admin/themes).

## Good to know

> Publishing saves the previous version to [Content history](/admin/revisions) first, so you can always go back.

- Use plain text. Formatting codes aren't turned into HTML.
- Keep the page description to about 140–160 characters. Search engines may shorten or rewrite it.
- Only fonts uploaded on the [Fonts](/admin/fonts) page, activated and licensed, can be chosen.
- **Show in navigation** on a section only matters while the header menu is automatic. See [Menus](/admin/help/menus).
- Maintenance mode hides the public site from visitors while you work. Remember to turn it off.
