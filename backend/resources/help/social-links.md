## What it does

List your profiles elsewhere, such as GitHub, LinkedIn, Bluesky or YouTube, and choose where each one appears on the site: the **header menu**, the **footer** or the **contact section**.

## Adding a profile

1. Choose the **platform** and paste the profile's full address.
2. Optionally change the **label**. It defaults to the platform name.
3. Tick where it should appear, then add it.

Use ↑ and ↓ to set the order. **Edit** a link to change it, untick **Enabled** to hide it everywhere without deleting it, or remove it.

## Good to know

- Addresses must start with `https://` and belong to the platform you chose, so a LinkedIn link must be on `linkedin.com`. Mastodon, website and "Other" accept any HTTPS address.
- Enabled links are also listed for search engines as your other profiles.
- No passwords or sign-ins are ever needed here.
- The GitHub profile in the [live site editor](/admin/site-editor) is still used for project repository links.
- Links show as text labels, not brand logos.
