## What it does

The media library holds the images used across the site: project covers, section images, backgrounds and the sharing image. Each image keeps a stable public address, so links keep working when you replace the file.

## Uploading

1. Drag images onto the upload box, or choose up to **10** at once.
2. Each image is uploaded separately, with a result line for each file. A file that's rejected doesn't stop the others.
3. Labels come from the file names. Change them on each card.

Use JPG, PNG or WebP, up to 5 MB each and at most 8192 pixels on a side. Every image is decoded and saved again, which also removes hidden details such as the camera's GPS location.

## Alt text

Alt text describes an image for people who can't see it, and helps search engines. After a batch upload, the library opens on **Missing alt text**, so you can describe each new image straight away. Write what the image shows in a sentence, for example "Dashboard of the Home Ledger app showing monthly spending".

## Finding and using images

- **Search** by label, file name or alt text.
- **Filter** by usage (used on the site, or unused), missing alt text, or file type, and **sort** by date, size or name.
- **Copy URL** copies the image's public address. **Download** saves the stored file.
- **Usage** on each card shows which projects, sections or settings use the image.

## Replacing and deleting

- **Replace image** swaps the file while keeping the same address everywhere it's used.
- **Delete unused image** only works when nothing uses the image, including saved history. This stops you from breaking a page by accident.

## Good to know

- Video, PDF and SVG files aren't accepted. Nothing on the site displays them, and SVG files can contain scripts.
